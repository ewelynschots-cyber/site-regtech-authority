# RegTech Authority — site institucional

Site institucional estático atualizado com o conteúdo de funcionalidades de verificação, análise contábil, screening, monitoramento e due diligence.

## Publicação

1. Abra `index.html` para uma visualização local, ou use o Live Server no VS Code.
2. Para publicar, envie a pasta inteira para GitHub e conecte o repositório à Vercel.
3. O contato é feito exclusivamente pelo e-mail `contato@regtechauthority.com.br`.

A marca exibida no cabeçalho utiliza a logo anexada e a sigla RA.
